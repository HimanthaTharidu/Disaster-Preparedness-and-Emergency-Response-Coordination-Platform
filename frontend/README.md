# DPERCP admin dashboard

React 18, Vite 6 and Tailwind CSS 4 (JavaScript). It holds the login and registration pages and the admin dashboard for the DPERCP API.

```bash
npm install
cp .env.example .env.local
npm run dev
```

Setup, environment variables, the preview/API auth modes and project status are described in the [root README](../README.md).

Source layout: `src/api` (fetch helpers), `src/pages` (one file per page), `src/components`, `src/layouts`, `src/locales.js` (English strings for the auth pages; Sinhala and Tamil are not added yet).
